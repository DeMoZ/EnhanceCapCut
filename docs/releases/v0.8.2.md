## An app icon

EnhanceCapCut has its own icon now: an hourglass "cut" mark in a cyan-to-magenta gradient with sparkles, on a dark
tile. On the Mac it shows in Finder, the Dock, Cmd+Tab and the Support window. On Windows it's on `EnhanceCapCut.exe`
and `ecc.exe` in Explorer, and on every window's title bar, taskbar button and Alt+Tab; the Support window shows it
too, like on the Mac. Nothing else changes.

## Downloads

- `EnhanceCapCut-0.8.2.pkg` — macOS app (Apple Silicon and Intel), installs into /Applications.
- `EnhanceCapCut-0.8.2-windows-x64.zip` — Windows app `EnhanceCapCut.exe` and command-line tool `ecc.exe`; unzip
  anywhere, no .NET or Windows App SDK install needed.

Both builds are unsigned: on macOS, allow the installer in System Settings ▸ Privacy & Security; on Windows,
SmartScreen may ask to confirm.
