## Automatic update checks on the Mac

The Mac version now checks for updates by itself, at launch and once a day, without asking first; the Windows
version already did. A newer version shows what's new and installs with one click. **Check for Updates…** in the app
menu and at the bottom of the export window still checks right away.

If you have 0.7.0, this update is the first one that arrives through the app: **Check for Updates…** installs it.

## Downloads

- `EnhanceCapCut-0.7.1.pkg` — macOS app (Apple Silicon and Intel), installs into /Applications.
- `EnhanceCapCut-0.7.1-windows-x64.zip` — Windows app `EnhanceCapCut.exe` and command-line tool `ecc.exe`; unzip
  anywhere, no .NET or Windows App SDK install needed.

Both builds are unsigned: on macOS, allow the installer in System Settings ▸ Privacy & Security; on Windows,
SmartScreen may ask to confirm.
