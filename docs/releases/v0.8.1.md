## A Donate button next to Export

**Donate…** at the bottom of the export window becomes a **♥ Donate** button next to **Export**. Every few seconds it
plays one short effect to remind about it — a heartbeat, the label swinging, a soft pink glow — and is still the rest
of the time. With Reduce Motion on the Mac, or animation effects turned off in Windows, it only glows. It opens the
same window with the ways to support EnhanceCapCut; nothing else changes.

## Downloads

- `EnhanceCapCut-0.8.1.pkg` — macOS app (Apple Silicon and Intel), installs into /Applications.
- `EnhanceCapCut-0.8.1-windows-x64.zip` — Windows app `EnhanceCapCut.exe` and command-line tool `ecc.exe`; unzip
  anywhere, no .NET or Windows App SDK install needed.

Both builds are unsigned: on macOS, allow the installer in System Settings ▸ Privacy & Security; on Windows,
SmartScreen may ask to confirm.
