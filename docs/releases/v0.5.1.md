## Windows: CapCut projects are found

**Windows:** 0.5.0 listed no projects at all. CapCut for Windows stores a project's draft in `draft_content.json`,
the Mac version in `draft_info.json`, and the app looked only for the second name. Both are accepted now, in the
project folder and in `Timelines/<id>/`, so `ecc list`, `ecc info`, the export window and the Subtitles &
Voice-over window see your projects, and the one open in CapCut is preselected again (CapCut for Windows keeps a
`.locked` file in it, like the Mac version).

Listing and reading projects is checked on CapCut for Windows (draft version 189.0.0). Rendering real Windows
projects hasn't been tried much yet; reports are welcome.

**macOS:** nothing changes for you; the project lookup takes the same two file names.

## Downloads

- `EnhanceCapCut-0.5.1.pkg` — macOS app (Apple Silicon and Intel), installs into /Applications.
- `EnhanceCapCut-0.5.1-windows-x64.zip` — Windows app `EnhanceCapCut.exe` and command-line tool `ecc.exe`; unzip
  anywhere, no .NET or Windows App SDK install needed.

Both builds are unsigned: on macOS, allow the installer in System Settings ▸ Privacy & Security; on Windows,
SmartScreen may ask to confirm.
