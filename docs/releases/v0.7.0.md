## Updates from inside the app

**New: Check for Updates.** Both versions can now find and install new releases themselves. The export window's
footer shows the version and a **Check for Updates…** link; on the Mac it's also in the app menu.

- **Mac:** updates come through Sparkle, the usual updater for Mac apps outside the App Store. It shows what's new,
  downloads the signed installer, checks its signature and installs it. It also checks by itself, at launch and once a day.
- **Windows:** the app checks GitHub once a day at launch; when a newer version is out, the link turns into
  **Update to x.y.z…**. Updating downloads the release zip, checks it against the checksum GitHub publishes, quits,
  replaces the files and starts the new version. Keep the EnhanceCapCut folder somewhere writable (not Program
  Files); otherwise the app offers the release page instead.

This version has to be installed by hand once, as before; from here on, the next ones arrive through the app.

## Downloads

- `EnhanceCapCut-0.7.0.pkg` — macOS app (Apple Silicon and Intel), installs into /Applications.
- `EnhanceCapCut-0.7.0-windows-x64.zip` — Windows app `EnhanceCapCut.exe` and command-line tool `ecc.exe`; unzip
  anywhere, no .NET or Windows App SDK install needed.

Both builds are unsigned: on macOS, allow the installer in System Settings ▸ Privacy & Security; on Windows,
SmartScreen may ask to confirm.
