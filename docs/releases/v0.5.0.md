## The Windows app

**Windows:** EnhanceCapCut now has an app, `EnhanceCapCut.exe`, with the same two windows as the Mac:

- **Export with EnhanceCapCut** — picks up the project open in CapCut and exports it with the same settings as on
  the Mac: aspect ratio, resolution, frame rate, H.264 / HEVC 8-bit / HEVC 10-bit, constant quality or bitrate,
  burned-in captions, loudness normalization (built in, no ffmpeg needed), output folder and file name. Features
  the renderer doesn't reproduce yet are listed before you export.
- **Subtitles & Voice-over** — transcribes the timeline (Whisper), translates it (NLLB-200) and adds captions and
  voice-over to the CapCut project, like on the Mac. The models (~1.5 GB) are downloaded once, from the window.

Starting the app again brings the export window back and re-detects the open project — pin it to the taskbar.

**Voice-over on Windows:** translated lines are spoken by Windows voices (choose female or male, a voice per
language, ▶ to preview; more voices in Settings ▸ Time & language ▸ Speech ▸ Add voices) and added as audio
tracks, one per language, with the same ducking of the original sound as on the Mac.

**Command line (Windows):** `ecc subtitles … --voice en,th --hear en --original keep|lower|mute --no-captions`,
and `ecc voices <language>` lists the installed voices.

The Windows version hasn't been tried on real CapCut for Windows projects yet; reports are welcome.

## Downloads

- `EnhanceCapCut-0.5.0.pkg` — macOS app (Apple Silicon and Intel), installs into /Applications.
- `EnhanceCapCut-0.5.0-windows-x64.zip` — Windows app `EnhanceCapCut.exe` and command-line tool `ecc.exe`; unzip
  anywhere, no .NET or Windows App SDK install needed.

Both builds are unsigned: on macOS, allow the installer in System Settings ▸ Privacy & Security; on Windows,
SmartScreen may ask to confirm.
