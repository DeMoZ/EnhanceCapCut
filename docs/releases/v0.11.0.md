## More of CapCut is rendered · Ещё больше из CapCut отрисовывается

On macOS and Windows. Now drawn like in CapCut:

- **Clip animations** — the In / Out fade, zoom, slide, rotate and shake on video and photo clips.
- **Blend modes** — all ten modes of CapCut's Blend panel (Screen, Multiply, Overlay, Soft light…), on clips and
  texts.
- **Stabilization** — all three levels, with the zoom following how much the clip shakes.
- **AI "Enhance quality"** — approximated: the clip is upscaled and sharpened.
- **Keyframe easing curves** — keyframes with a curve between them now ease instead of moving in a straight line.
- **Vertical text**.

Fixed: a keyframed clip whose start was trimmed stayed frozen on its first keyframe instead of moving.

Everything not reproduced yet is still listed in the export window and in the README.

На macOS и Windows. Теперь рисуются как в CapCut:

- **Анимации клипов** — появление и исчезновение (растворение, приближение, сдвиг, поворот, тряска) у видео и фото.
- **Режимы наложения** — все десять режимов панели «Наложение» CapCut (Экран, Умножение, Перекрытие, Мягкий свет…),
  у клипов и текстов.
- **Стабилизация** — все три уровня, с увеличением по тому, насколько клип трясётся.
- **ИИ «Улучшение качества»** — приближённо: клип увеличивается и становится резче.
- **Кривые ключевых кадров** — между ключевыми кадрами с кривой движение теперь плавное, а не по прямой.
- **Вертикальный текст**.

Исправлено: клип с ключевыми кадрами и обрезанным началом застывал на первом ключевом кадре вместо движения.

Всё, что пока не воспроизводится, по-прежнему перечислено в окне экспорта и в README.

## Voice on Windows · Голос на Windows

Isolate voice, reduce noise, enhance voice and the voice filters (Booming, Live House, Old Hollywood) now work on
Windows too, like on the Mac. Isolating the voice downloads a small model (about 9 MB) the first time.

Выделение голоса, шумоподавление, улучшение голоса и голосовые фильтры (Booming, Live House, Old Hollywood) теперь
работают и на Windows, как на Mac. Для выделения голоса при первом использовании скачивается небольшая модель (около
9 МБ).

## Subtitles · Субтитры

- **Thai subtitles** are made twice as large as the caption style, because Thai letters come out small in CapCut's
  caption font. Lines are shorter to match.
- **On Windows, Thai, Lao, Khmer and Burmese subtitles now break between words** instead of at any character.
- A number stays on one line with the word after it in these languages.

- **Тайские субтитры** делаются в два раза крупнее стиля субтитров: в шрифте субтитров CapCut тайские буквы
  получаются мелкими. Строки под это стали короче.
- **На Windows субтитры на тайском, лаосском, кхмерском и бирманском теперь переносятся между словами**, а не на
  любом символе.
- Число в этих языках остаётся на одной строке со словом после него.

## One core for Mac and Windows · Общее ядро для Mac и Windows

Reading CapCut projects, building the timeline, the export report, splitting subtitles into lines and writing
subtitles and voice-over back into the project are now one shared code base on both platforms. The Mac and Windows
versions read the same project the same way, and `ecc info` prints the same report on both. On Windows, `ecc` output
is now UTF-8, so non-Latin project and file names come out right.

Чтение проектов CapCut, сборка таймлайна, отчёт экспорта, разбивка субтитров на строки и запись субтитров и озвучки
обратно в проект теперь общий код на обеих платформах. Версии для Mac и Windows читают один и тот же проект
одинаково, и `ecc info` выводит на обеих один и тот же отчёт. На Windows вывод `ecc` теперь в UTF-8, поэтому
нелатинские имена проектов и файлов показываются правильно.

## Voice cloning on Intel Macs · Клонирование голоса на Mac с Intel

Voice cloning now needs a Mac with Apple silicon: the library it runs on is no longer published for Intel Macs. On an
Intel Mac the option is turned off and says so; subtitles and voice-over in system voices still work.

Клонирование голоса теперь требует Mac с Apple silicon: библиотеку, на которой оно работает, больше не выпускают для
Mac с Intel. На Mac с Intel этот вариант выключен с пояснением; субтитры и озвучка системными голосами работают
по-прежнему.

- `EnhanceCapCut-0.11.0-windows-x64.zip` — Windows app `EnhanceCapCut.exe` and command-line tool `ecc.exe`; unzip
