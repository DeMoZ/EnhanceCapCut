## Subtitles

**macOS:** a new **Subtitles & Voice-over** window (in the export window, or Window ▸ Subtitles & Voice-over, ⌘U)
transcribes the speech of a timeline, translates it and adds the result to the CapCut project as native caption
tracks — open the project in CapCut and they're there, editable like CapCut's own auto-captions. One track per
language; pick which is shown, the others are added hidden. Runs offline with Apple's speech recognition and
Translation (needs macOS 26). Close the project in CapCut before creating subtitles; the project file is backed
up first. Voice-over comes later.

**Windows:** the same from the command line: `ecc subtitles "My Project" --language ru --translate en,th`.
Offline with Whisper (speech) and NLLB-200 (translation); the models (~1.5 GB) are downloaded on first use.

## Downloads

- `EnhanceCapCut-0.3.0.pkg` — macOS app (Apple Silicon and Intel), installs into /Applications.
- `EnhanceCapCut-0.3.0-windows-x64.zip` — Windows command-line tool `ecc.exe` (`list`, `info`, `render`,
  `subtitles`); unzip anywhere, no .NET install needed. Not yet tested on real projects on Windows.

Both builds are unsigned: on macOS, allow the installer in System Settings ▸ Privacy & Security; on Windows,
SmartScreen may ask to confirm.
