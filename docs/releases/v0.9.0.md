## Русский интерфейс · Russian interface

The whole app now speaks **English or Russian**: the export, subtitles and donate windows, the menus, dialogs,
progress messages, the "Not rendered yet" list and the language names. It follows the system language; the new
**🌐 menu** at the bottom of the export window switches it right away, without a restart. The `ecc` command line
stays English.

Приложение теперь целиком на **русском или английском**: окна экспорта, субтитров и поддержки, меню, диалоги,
сообщения о ходе работы, список «Пока не отрисовывается» и названия языков. По умолчанию — язык системы; меню **🌐**
внизу окна экспорта переключает язык сразу, без перезапуска.

## How to Use

A built-in guide, **How to Use EnhanceCapCut**: quick start, setting up the hotkey (Mac) or the taskbar (Windows), the
export window, subtitles and voice-over, dubbing in the speaker's own voice, and tips. It opens once at the first
launch, then from **Help ▸ EnhanceCapCut Help** (⌘?) on the Mac or the **How to Use** link at the bottom of the
export window on both platforms. In English and Russian.

## Downloads

- `EnhanceCapCut-0.9.0.pkg` — macOS app (Apple Silicon and Intel), installs into /Applications.
- `EnhanceCapCut-0.9.0-windows-x64.zip` — Windows app `EnhanceCapCut.exe` and command-line tool `ecc.exe`; unzip
  anywhere, no .NET or Windows App SDK install needed.

Both builds are unsigned: on macOS, allow the installer in System Settings ▸ Privacy & Security; on Windows,
SmartScreen may ask to confirm.
